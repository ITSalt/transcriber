## Симптом
Markdown протокола (пользовательский контент, правится в UC-301) рендерится в HTML без санитизации и отдаётся Puppeteer с ожиданием `networkidle0`: протокол может содержать `<img src="http://127.0.0.1:3010/…">` или `<script>` и заставить headless-браузер на сервере обращаться к внутренним адресам (SSRF) и ждать их.

## Воспроизведение
1. В протокол встречи вставить `<img src="http://127.0.0.1:3010/api/health">` (или внутренний адрес).
2. Экспортировать PDF — Puppeteer выполняет запрос изнутри сервера.

## Ожидалось и получено
Ожидалось: HTML из Markdown санитизируется (без raw HTML/скриптов), сетевые запросы страницы блокируются (`page.setRequestInterception` → abort для всего, кроме data:/локальных шрифтов), таймаут рендера. Получено: `sanitize:false`, `networkidle0`, без перехвата запросов.

## Подтверждение
Сообщение product-backend 2026-10-07 (ref=api/src/lib/pdf.ts:110); код на main.

## Причина
Предсуществующее решение рендера PDF (UC-301/ADR-009) без модели угроз для пользовательского HTML.
