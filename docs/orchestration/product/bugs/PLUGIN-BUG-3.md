# PLUGIN-BUG-3 — Замок **/package.json «сталкивается» с web/src/i18n/** по глобу на несуществующем файле

| Поле | Значение |
|------|----------|
| Найден | 2026-10-07, dispatch второго пакета волны 1 |
| Окружение | pepper-orchestrator 0.11.0, Claude Code 2.1.292, Ubuntu 24.04, Python 3.12 |
| Модуль | плагин: orch.py dispatch / lock (collision by glob) |
| Серьёзность | low |
| Статус | открыт; Issue: см. ниже |

## Симптом
`dispatch WP-FRONTEND-01` отказан: замок `**/package.json` (держит WP-BACKEND-06) «пересекается» с `web/src/i18n/**`, хотя файла `web/src/i18n/package.json` нет и никто его не создаёт. `--dry-run` обоих пакетов до первого dispatch проходил.

## Воспроизведение
1. Пакет A объявляет общий путь `**/package.json`; пакет B — `web/src/i18n/**`.
2. `dispatch A`, затем `dispatch B` → отказ.

## Ожидалось и получено
Ожидалось: столкновение по реальному дереву или предупреждение в `overlap --planned`/`--dry-run` заранее. Получено: отказ только на втором живом dispatch.

## Подтверждение
Журнал status.md 2026-10-07 16:48Z (сужение объявления WP-BACKEND-06 до четырёх манифестов).

## Причина
Коллизия замков считается по пересечению глобов, без проверки по дереву репозитория.
