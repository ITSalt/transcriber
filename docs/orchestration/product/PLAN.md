# Модернизация Transcrib до продукта — план

> Пишется один раз, правится редко. Текущее состояние — в `status.md`.

## Цель и условие завершения

Превратить Transcrib из открытого однопользовательского MVP в продукт для нескольких
пользователей: вход по PIN, изолированные рабочие пространства, список задач, проекты с
накопленным контекстом, который реально улучшает распознавание и протокол, и сбор обратной
связи по протоколам для следующей программы (улучшение воркфлоу протоколов).

Условие завершения (проверяется фактами на PROD https://transcriber.itsalt.ru):

1. Без входа любой `/api/*`, кроме `/api/health` и `/api/auth/login`, отвечает 401; SPA
   показывает экран входа.
2. Два пользователя в разных пространствах: GET/PUT/DELETE/скачивание/PDF/SSE чужой встречи по
   известному id отвечают 404; список задач пользователя содержит только встречи его пространств
   (живой сценарий + интеграционный тест изоляции по всем маршрутам).
3. Встреча, запущенная с проектом и контекстом: в запросе к Deepgram есть `keyterm` из
   участников/глоссария, в промпте LLM — типизированные секции контекста; снимок контекста и
   метаданные генерации сохранены (SELECT).
4. Пользователь отправил обратную связь всех трёх видов (текст, исправленный протокол, файл .docx);
   записи и файлы видны SELECT'ом и в S3; исходный сгенерированный протокол не перезаписан.
5. Пакеты программы в DONE. Затем `close`; анализ обратной связи — следующая программа.

## Объём

1. Аутентификация (D-8): вход только по уникальному 6-значному PIN (хранится только хеш),
   сессия в httpOnly-cookie; после 10 неудач — бессрочная блокировка клиента, снимается вручную,
   текст «Больше нельзя, пиши Максу для разблокировки»; пользователи заводятся CLI-скриптом (A-1).
2. Рабочие пространства и членство (D-6: пространство — единица изоляции, личное у каждого +
   общие); изоляция на уровне API, worker, S3-ключей, SSE. Существующие прод-встречи — в
   пространство «Роман» (D-7).
3. Список задач (= встреча: файл + протокол) в рамках текущего пространства; переключатель
   пространств.
4. Типизированный контекст встречи перед распознаванием: участники, стороны, тип/цель, повестка,
   глоссарий, предыдущий протокол, свободные заметки. Маршрутизация: имена/термины → Deepgram
   `keyterm`; всё → LLM в XML-секциях как данные. Снимок использованного контекста + метаданные
   генерации (модель, версия промпта, keyterms).
5. Проект в пространстве: карточка участников, глоссарий, описание; при запуске задачи
   подставляется, пользователь добавляет только дополнения. Память проекта (D-11): после каждого
   протокола автоматически обновляются сводка проекта и реестр задач/решений с переносом открытых
   задач между встречами; хранение — граф по итогам Q-3; память подаётся в промпт следующей встречи.
6. Обратная связь: неизменяемая сгенерированная версия + история правок; отзыв-текст;
   «правильный протокол» (текст/файл); .docx с комментариями/правками — файл + разбор в JSON
   (D-12). Только накопление.
7. Дизайн веба на токенах ITSALT (D-5).

### Не входит

- Анализ обратной связи и изменение воркфлоу протоколов по ней — следующая программа.
- Админка, самостоятельная регистрация, восстановление PIN, роли внутри пространства.
- Выбор LLM-модели пользователем (сейчас адаптер принимает только claude-sonnet-4-6,
  `worker/src/llm/kieai.ts:183-187`), чанкинг длинных транскриптов.
- Отдельный UI ручного сопоставления спикеров (D-10 — только атрибуция в промпте).
- Staging-стенд (D-3), тёмная тема.

## Факты

Собраны 2026-10-07 субагентами (код на `main` 343f4a1, документация вендоров).

**Авторизации нет совсем.** Маршруты помечены «NFR-007: No authentication at MVP»
(`api/src/routes/uc-001.ts:6` и uc-002/003/004/201/301/302); «RQ-003: AUTHOR sees only own
meetings; deferred until auth» (`api/src/services/uc-001.service.ts:8`). Нет модели User/сессий,
нет cookie/cors-плагинов (`api/package.json:25`). Прод — Caddy без basic_auth
(`.tl/scripts/transcrib-caddyblock.conf:3-52`; живой Caddyfile не в git — не проверен). В графе
одна роль AUTHOR (SR-01) и UC-001..302.

**Данные.** `Meeting` без владельца (`api/prisma/schema.prisma:50-65`), дочерние сущности 1:1 с
Cascade. 5 миграций, последняя `20260814120000_uc200_transcript_detected_language`; применяются
`prisma migrate deploy` в `deploy-production.yml:57-58` до рестарта pm2 — пока работают старые
процессы. На проде есть реальные встречи (`.tl/release-status.json:80`, `.tl/changelog.md:336`) —
новый FK должен быть заполнен бэкфиллом.

**Пайплайн.** upload init/complete (`api/src/routes/upload-*.ts`), `finalizeUpload`
(`api/src/services/uc-100.service.ts:126-258`) создаёт Meeting и сразу ставит транскрипцию в
очередь (`:244-247`) — сейчас нет паузы «перед распознаванием». S3-ключи `pending/<uuid>.<ext>`
(`upload-init.ts:17-72`).

**Deepgram.** `nova-3, diarize, smart_format, utterances, punctuate`, language/detect_language,
min/max_speakers (`worker/src/asr/deepgram-adapter.ts:137-146,214-240`); `keyterm` не передаётся.
`IAsrProvider` уже расширялся опциональной подсказкой `speakerCount`
(`shared/src/asr/IAsrProvider.ts:17-39`). Документация: `keyterm` поддержан Nova-3 моно и multi,
лимит 500 токенов на запрос, рекомендовано 20–50 терминов; явного подтверждения для `ru` нет —
нужен замер (Q-1). `min_speakers/max_speakers` в документации диаризации не найдены (Q-2).

**LLM.** Системный промпт — статический файл `worker/src/llm/prompts/ru/protocol.md` (XML-блоки,
4 обязательных раздела, `protocol-generation.ts:63-65`); в user-сообщение идёт только
`transcript.rawText` (`protocol-generation.ts:190-195`); слота для контекста нет; max_tokens 4096
(`kieai.ts:129`).

**Протокол.** `PUT` перезаписывает `markdownContent`, растит version/editCount
(`api/src/services/uc-301.service.ts:79-82`); истории нет, исходный ответ LLM теряется после
первой правки — для обратной связи это надо исправить до любых правок пользователей.

**Фронт.** Маршруты `/`, `/upload`, `/meetings/:id[/transcript|/protocol]` (`web/src/App.tsx:12-37`),
нет логина и app shell. Дизайн — стоковые токены shadcn (`web/src/styles/globals.css:1-40`),
своей дизайн-системы нет. ITSALT Diorama: `itsalt-site/web/assets/css/tokens.css` (палитра
paper/graphite/orange #F4510B/petrol, Inter Tight/Inter/JetBrains Mono, радиусы 10/14/20),
только светлая тема.

**Библиотек разбора docx нет** (mammoth/jszip отсутствуют). Комментарии — `word/comments.xml` +
`w:commentRangeStart/End`, правки — `w:ins`/`w:del`(`w:delText`); надёжно — JSZip + XML-парсер.

**Тесты.** Vitest: api ~194, worker ~205, web ~150, shared ~77 кейсов; CI гоняет миграции на
Postgres (`.github/workflows/ci.yml:75-90`); Playwright-спеков нет (QA через /nacl-tl-qa).

## Риски

| Риск | Вероятность | Влияние | Мера |
|------|-------------|---------|------|
| Merge в main = прод (D-3): API с авторизацией без экрана входа ломает прод | высокая | высокое | BACKEND-01 и FRONTEND-02 доставляются подряд в одном окне; до FRONTEND-02 BACKEND-01 держится ACCEPTED |
| Миграция с FK на существующие встречи падает или ломает старые процессы | средняя | высокое | Аддитивная миграция: nullable → бэкфилл → NOT NULL в той же миграции; R-бэкап БД владельцем, блокирует доставку (D-4) |
| Перебор PIN: вход только по PIN (D-8), один миллион общих вариантов, при N пользователях шанс попасть в кого-то растёт в N раз; смена IP обходит блокировку | средняя | высокое | Принято владельцем для MVP ограниченного круга; блокировка клиента после 10 неудач, глобальный счётчик неудач в логе, медленный хеш; пересмотреть до открытия сервиса шире |
| Утечка через обходные пути (S3 presigned, PDF, SSE, скачивание транскрипта) | средняя | высокое | Тест изоляции перечисляет все маршруты; ключи S3 с префиксом пространства; presign только после проверки доступа |
| `keyterm` не даёт эффекта на русском или тарифицируется | средняя | низкое | Q-1: A/B на 2–3 прод-записях до включения по умолчанию; флаг в env |
| Prompt injection через контекст/предыдущий протокол | средняя | среднее | Контекст только в user-сообщении в XML-тегах как данные; экранирование закрывающих тегов |
| Правки протокола до BACKEND-03 теряют исходник | высокая | среднее | В BACKEND-01 не трогаем; BACKEND-03 первым шагом сохраняет текущий текст как версию 1 бэкфиллом |
