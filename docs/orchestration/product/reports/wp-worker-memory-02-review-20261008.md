## 4. Находки

**M-1 (Medium) — `worker/src/memory/gate.ts:378-384`: страховка Jaccard поглощает решение с изменённым числом/датой или отрицанием.** Сценарий: в памяти `D-6 «… до 19 мая»`; на новой встрече LLM возвращает `NEW` для «… до 26 мая» без `supersedes_code` → Jaccard 0,778 → `newDecisions: []`, упоминание у D-6, `notes: []`. То же для «Не подаём на сертификацию…» vs «Подаём…» (0,857). Память хранит устаревшее решение как действующее, сводка об изменении не узнаёт, событий для подтверждения нет (D-14 не задействован). Требовать: не считать дублем при расхождении числовых токенов (`\p{N}`) или токенов-отрицаний (`NEGATIONS` из `transcript.ts:43` уже есть) между текстами — тогда создаётся новое решение (а при наличии `supersedes_code` — замена); плюс юнит-тест на оба случая и `notes`-заметка (pending) при срабатывании страховки без `duplicate_of`, чтобы след оставался. Не регрессия относительно базы (база создавала дубль, но не теряла), но новая потеря информации.

**L-1 (Low) — `gate.ts:382`: дубль внутри одной встречи не получает упоминания.** Если `dupCode` — решение, созданное в этой же встрече (есть в `known`, нет в `recent`), ветка `if (recent.has(dupCode))` пропускает `decisionMentions`, вторая цитата теряется. `writeMeetingUpdate` создаёт новые решения раньше упоминаний (`meeting-update.ts:236-266`), MATCH по коду сработал бы. Требовать: убрать условие либо объяснить в комментарии.

**L-2 (Low) — `gate.ts:381`: `supersedes_code` теряется, если Jaccard указал на другое решение.** LLM: `NEW`, `supersedes_code: 'D-5'`, текст на 0,6+ похож на D-6 → `dupCode = 'D-6' !== 'D-5'` → решение выброшено, замена D-5 не записана. Редкий случай; достаточно теста/комментария или приоритета `supersedes_code` над страховкой.

**L-3 (Low, заявлено) — `gate.ts:128-141`: нет обработки падежей.** «Антону», «Сергею» → PENDING даже для участника «Антон». Приемлемо по D-14 (пользователь подтверждает), но в проде русские транскрипты дадут заметную долю PENDING по исполнителям; стоит зафиксировать как follow-up (нормализация окончаний или алиасы в падежах).
