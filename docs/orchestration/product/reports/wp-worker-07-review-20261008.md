## 3. Ответы на вопросы

**Q1 — расхождение основ по длине (подтверждено).** `protocol-guard.ts:22` `stemOf = word.slice(0, max(3, len−2))`; сравнение `:57` требует точного равенства основ. Одноразовый тест в клоне (файл удалён): транскрипт «Передай это Антону и Тенгизу», буллеты «- Антон — руководитель», «- Тенгиз — упоминается» → `removed = ["- Антон — руководитель","- Тенгиз — упоминается"]` — **оба удалены**. Таблица пар (буллет ← транскрипт): Антон←Антона REMOVED, Максим←Максимом REMOVED, Тенгиз←Тенгизу REMOVED, Роман←Романа REMOVED, Роман←Роману REMOVED, Борис←Борису REMOVED, Ильнур←Ильнура REMOVED; Серафима←Серафиме, Павел←Павла, Виолетта←Виолетты, Никита←Никиту, Иван←Ивана, Олег←Олега, Мария←Марии — kept. Обратное направление тоже ломается: буллет «Антона» при «Антон» в транскрипте → REMOVED; «Максимом» при «Максим» → REMOVED. Закономерность: для имён длиной 5–6 букв (len−2 = 3..4) любое окончание в +1 букву даёт другую основу. Это REVISE-пункт; фикс — сравнивать основы по префиксному отношению (`a.startsWith(b) || b.startsWith(a)` при общей длине ≥ 4) либо фиксированный префикс `min(len, 5)`/`len−2` с обеих сторон одной длины, и добавить эти пары в `protocol-guard.test.ts`.
